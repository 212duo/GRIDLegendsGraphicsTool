# GRID Legends 画质工具 v1.4.0

## 更新内容

- 画质档位支持 `3=高`、`4=极高`，极限预设会写入 4 档。
- 补齐环境光遮蔽、光照质量、后视镜、粒子效果、轮胎痕迹和天气效果等画质项。
- 修改当前画质后，会同步更新游戏 `Graphics` 预设档位，减少重启游戏后被旧预设覆盖的情况。
- 兼容缺少目标字段的配置文件，保存时会补写对应的配置项。
- 保留 Android 平台对 MetalFX 的安全处理，不主动写入不适用的 MetalFX 配置。

## 配置与兼容性说明

修改前请关闭游戏并备份原 `preferences` 文件。极高画质、HDR 和高帧率会显著增加性能、功耗和发热；部分设备或游戏版本不支持的项目可能被游戏忽略或自动降档。

## 测试说明

本版本已完成画质参数自动化测试、Release 安装包构建及 Release 签名校验。

受测试环境限制，未覆盖不同厂商设备、不同 GPU、HDR 屏幕及实际游戏内逐项显示结果。不同设备或系统版本下可能存在差异，如遇问题，请通过 GitHub Issues 反馈。
