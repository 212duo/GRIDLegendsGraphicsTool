# GRID Legends 画质工具 v1.3.0

## 新增配置项

本版本新增 9 项可调整的画质配置：

- 环境光遮蔽
- 光照质量
- 后视镜
- 粒子效果
- 轮胎痕迹
- 天气效果
- 渲染倍率
- 垂直同步
- 减少雨水

## MetalFX 安全处理

Android 平台不支持 Apple MetalFX。本版本不会主动修改 `MetalFX`，避免向 Android 游戏配置写入不适用的图形选项；配置文件中已有的 MetalFX 值也不会由本工具主动变更。

## 兼容性

新增配置项基于内置的 20 份真实 GRID Legends Android `preferences` 配置验证，覆盖低配、中配、高配和极限四组预设。不同设备、游戏版本和 ROM 的实际表现可能不同，请按设备性能逐步调整。

## 安装与备份提醒

- 安装新版本前，建议保留当前 APK 和已导出的 `preferences` 文件副本。
- 直接编辑游戏配置前，先关闭 GRID Legends；应用保存前会创建备份文件。
- 手动替换导出的 `preferences` 前，先关闭游戏并自行备份原文件。
- 极限和 HDR 预设负载较高，低端设备可能出现卡顿、闪退或无法进入游戏。
