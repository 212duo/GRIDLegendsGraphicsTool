# GRID Legends 画质工具 v1.5.0

本版本集中修复保存逻辑、预设准确性和文件读写安全问题，建议所有 v1.4.0 用户更新。

## 重要修复

- **修改一项不再改动整个 Graphics 档位。** v1.4.0 保存或导出时，即使只改了一项，也会用当前值覆盖 `Graphics` 档位中的十几项（例如只改阴影，会连带改动帧率、抗锯齿、镜子等 16 个档位值）。现在只写入实际修改的字段，同步也只针对被修改的当前值。
- **保存前校验写入结果。** 写入内容会先重新解析，任何字段未成功写入都会取消保存并提示具体字段，不再出现“提示成功但没生效”或写错区块的情况。
- **编辑页“应用预设”改用 20 份真实配置。** 原先编辑页的 8 个预设是按公式生成的，与真实配置有 5–35 项差异。现在直接读取内置的 20 份真实 `preferences`，应用画质项和 `Graphics`/`Performance` 档位；当前配置中不存在的字段会跳过并提示。
- **“极高”档标注为实验。** 20 份真实配置中从未出现 4 档。“极高”仍可手动选择，但会标注“实验”并提示风险，预设不再自动写入 4 档。

## 更安全的保存与恢复

- 保存流程统一为：校验内容 → 备份原配置 → 写入 → 读回比对，失败时自动还原原配置。
- Root/Shizuku 模式先把内容分块写入临时文件，解码成功后才覆盖配置，传输中断不会把配置截断为空。
- 自动备份只保留最近 5 份；编辑页右上角新增“恢复备份”，可按时间选择并还原（还原前会再备份当前配置）。
- 原“恢复默认”按钮更名为“撤销未保存修改”，与实际行为一致。
- Root/Shizuku 模式保存前会检测游戏是否在运行，可选择“关闭游戏并保存”；SAF 模式无法检测，会在保存按钮上方提示先关闭游戏。

## 稳定性

- 首页检测、Root 授权、目录诊断以及编辑页的加载、保存、导出都移到后台线程，Root 授权弹窗期间界面不再卡死。
- 修复编辑页每次进入都会泄漏 Shizuku 监听的问题。
- 首页选择的访问方式在返回或旋转屏幕后保持不变。
- SAF 授权失败不再导致闪退，重新授权时会释放旧授权。

## 细节改进

- 配置值不在选项列表中时，会显示“当前值：X（非标准值）”。
- 分辨率滑块不再绘制上千个刻度。
- 动态分辨率下限高于上限时给出提示（部分真实预设本身就是这样设置的，不会阻止保存）。
- 关于页显示的版本号改为自动读取（v1.4.0 误显示为 v1.3.0）。

## 测试说明

本版本新增基于 20 份真实 `preferences` 的自动化测试，覆盖：只改一项时的字段变化范围、未修改时文件逐字节不变、每份预设应用后的写回结果、保存/备份/恢复流程，以及 Root/Shizuku 分块写入与解码失败时的保护。已完成 Release 构建与签名校验。

受测试环境限制，**本版本未在真机上验证** Root、Shizuku、SAF 的实际写入，以及游戏读取修改后的显示效果。新增的“游戏运行检测”“分块写入”“恢复备份”依赖设备 shell 环境（`pidof`、`base64`、`am`），不同 ROM 可能存在差异。如遇问题，请通过 GitHub Issues 反馈，并可在编辑页“恢复备份”中还原。
