# 1.3 画质配置项补全实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 `executing-plans` 在当前隔离 worktree 中逐任务执行本计划，并以复选框跟踪进度。

**目标：** 为编辑器增加 9 个经真实 Android `preferences` 验证的配置项，停止改写 MetalFX，并发布签名的 1.3.0 APK。

**架构：** 保持 `ParamDefinitions` 作为可编辑字段的唯一清单，通过现有 `ConfigParser`/`ConfigWriter` 完成顶层和 `Graphics` 档位的读写。生成式预设补齐新顶层值并移除 MetalFX 写入；20 份完整内置预设不改字节，只通过新增参数定义自动获得编辑入口。

**技术栈：** Kotlin 2.0、Jetpack Compose、XmlPullParser、JUnit 4、Gradle Android Plugin 8.7.3。
